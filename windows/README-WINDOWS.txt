COOLWALLET FOR WINDOWS x86_64
================================

START
-----
Double-click START-COOLWALLET.bat.

The launcher starts the daemon, waits for RPC, creates or loads the wallet
named coolwallet, and starts CoolWallet.exe.

STOP
----
Double-click STOP-COOLWALLET.bat.

DATA
----
The blockchain and wallet are stored inside the data folder.

SECURITY
--------
Do not publish a populated data\wallets folder or any wallet.dat file.
The included configuration contains no RPC username or password and restricts
RPC to the local machine.

WINDOWS NOTICE
--------------
Unsigned cryptocurrency software may trigger Microsoft Defender or SmartScreen.
Verify the SHA-256 checksum before running it.
